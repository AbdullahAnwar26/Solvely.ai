- (event) Fast path; user delegated all decisions. Spine only deliverable (build-substrate).
- (decision) Paradigm: modular monolith with ports-and-adapters around teaching domain; AI provider behind a port. Alternatives weighed: microservices (rejected: 8GB machine, solo), plain Django layered (rejected: provider/board rules leak into views).
- (decision) Board mutation only via validated BoardOperation list applied by one frontend adapter; model never returns raw Excalidraw JSON/HTML/JS. Prevents arbitrary-state injection and layout drift.
- (decision) Board persistence: append-only BoardRevision with integer revision + optimistic concurrency (If-Match style, 409 on stale). Learner vs AI elements tagged via customData.origin; AI updates never touch origin=learner.
- (decision) Auth: Django session cookies + CSRF, same-origin deployment (Django/whitenoise serves built SPA; Vite proxy in dev). No tokens in browser storage. Every queryset scoped by owner.
- (decision) AI calls synchronous inside request with explicit timeout, bounded retries, per-process concurrency semaphore; no Celery/Redis in v1 (no background need). Cancel = client abort. Step delivery: plan call then one call per Step requested by client; no SSE in v1.
- (decision) Usage: UsageRecord per generation; per-user daily Lesson Allowance + global daily ceiling checked and charged in one transaction before provider call; refunded on provider failure.
- (decision) Gemini model id only from env GEMINI_MODEL; prompts and JSON schemas versioned in code (prompts/v1). Provider SDK google-genai confined to apps/api/ai/providers/gemini.py.
